# 《信逢 Inkling · MVP 信息架构与页面流程》

> 世界观：漂流邮局 · Slogan：让社交回归真诚与纯粹
> 范围：本文档严格聚焦已确认 MVP 范围。被砍掉的复杂经济/装扮矩阵/向量召回/关系仪式等不在本文，仅在末尾"演进锚点"中标注接口预留。
> 交付目标：可直接交付前端实现（移动优先 PWA，375–430px 主视口）。

---

## 0. 全局约定（贯穿所有页面）

**去人格化原则（硬约束）**
- 永不显示"已读 / 对方在线 / 最后活跃 / 正在输入"。
- 打捞预览永不露真人照片，仅露"文字名片 + 文字标签 + 信件前几行"。
- 时间一律模糊化："刚刚漂来 / 在途中 / 已漂泊 N 天"，不显示精确时间戳（结缘后笔友信匣内可显示日期，不显示秒级）。

**世界观文案词典（统一术语，前端硬编码用此表）**
| 系统概念 | 界面用词 |
|---|---|
| 发信 | 投递 / 寄出漂流瓶 |
| 信件审核中 | 邮局正在分拣 |
| 在途 | 信鸽振翅 / 车马劳顿（粗档时延） |
| 进入可打捞池 | 漂入海面 |
| 打捞 | 打捞一封漂流信 |
| 预览锁定 | 拆封前的犹豫（10 分钟） |
| 拆封 | 拆开火漆封印 |
| 回信窗口 | 7 天回信潮汐 |
| 成为笔友 | 结缘 / 缔结笔友 |
| 超时回池 | 信重新漂回海面 |
| 拉黑/举报 | 退回邮局 / 投诉信使 |
| 隐身 | 闭关 |
| 守护模式 | 未成年守护 |

**配额展示（顶部或卡片角标）**
- 今日：投递 1 / 打捞 3 / 拆封 1。用墨水滴或火漆印图标 + 剩余数字。耗尽显示灰态 + "明日潮汐再启"。

**底部全局 Tab（4 项，固定 56–64px，含安全区适配）**
`[漂流海] [我的信件] [笔友信匣] [我的]`

## 1. 全站信息架构（IA）

```
信逢 Inkling (PWA)
│
├── 启动/鉴权层（无 Tab）
│   ├── 启动屏（漂流邮局开场动画）
│   ├── 登录 / 注册
│   ├── 年龄声明门控（强制，未成年人保护前置）
│   └── 首次资料引导（昵称 → 自报MBTI → 兴趣标签 → 偏好滑杆 → 地理授权）
│
├── [Tab1] 漂流海  (默认首页)
│   ├── 海面打捞页（今日 3 次打捞入口）
│   ├── 打捞预览卡（10 分钟预览锁，半张名片）
│   ├── 拆封读信页（拆火漆 → 全文）
│   └── 回信页（启动 7 天窗口）
│
├── [Tab2] 我的信件 (我寄出的)
│   ├── 在途中（信鸽动画 + 粗档进度）
│   ├── 已送达（已漂入海/已被打捞，去人格化）
│   ├── 已结缘（跳转笔友信匣）
│   └── 写信编辑器（投递入口，FAB 浮动按钮）
│
├── [Tab3] 笔友信匣 (已结缘关系)
│   ├── 笔友列表
│   └── 笔友往来会话（保留在途延迟，非即时聊天）
│
└── [Tab4] 我的
    ├── 个人资料（昵称/自报MBTI/兴趣标签/文字名片）
    ├── 设置
    │   ├── 未成年守护模式
    │   ├── 隐身（闭关）
    │   ├── 通知节奏
    │   └── 偏好滑杆（相似↔互补 等）
    ├── 安全中心（举报/拉黑记录、申诉入口）
    └── 账号与隐私（注销、数据导出-GDPR、协议）
```

**IA 设计要点**
- "写信投递"入口放在 **我的信件** Tab（FAB），而非漂流海——因为漂流海是"打捞别人"，我的信件是"管理我寄出的"，投递逻辑归属"我寄出"心智。
- 拆封/回信是漂流海打捞流程的延续，路由上挂在漂流海下；但拆封后的信进入 **我的信件→（若回信成功）已结缘** 与 **笔友信匣**。
- 未成年守护模式贯穿全局：开启后影响审核阈值、可见范围、通知时段，状态常驻"我的"页顶部徽章。

## 2. 关键流程页面级流转图

### 2.1 注册与年龄门控引导（强制合规前置）

```
[启动屏]
   │ 首次进入
   ▼
[登录/注册] ──已有账号──► 登录 ──► 年龄已确认? ──是──► [漂流海]
   │ 新用户                              │否
   ▼                                     ▼
[年龄声明门控] ◄───────────────────────────┘
   │
   ├─ 输入出生日期(或选择年龄段)
   │
   ├─► 判定 ≥18 ──► [资料引导:昵称]
   │
   ├─► 判定 13–17(未成年)──► 强制[未成年守护说明页]
   │        │ 需监护提示/区域法规文案(GDPR-K/COPPA/PDPO/個資法)
   │        ▼
   │     [守护模式默认开启确认] ──► [资料引导:昵称]
   │
   └─► 判定 <13(或低于目标地最低年龄)──► [婉拒页:暂不能开启漂流]
                                          (不可继续，提供申诉/客服入口)

[资料引导:昵称]
   ▼
[自报MBTI] (含"不确定/不知道"分支 → 引导轻量自测 or 跳过=未知)
   ▼
[兴趣标签] (至少选 3 个)
   ▼
[偏好滑杆] (相似↔荣格互补 / 就近↔远方)  ← 可跳过用默认
   ▼
[地理授权] (仅取 GeoHash 前5位，文案明示"不存精确位置")
   ├─ 同意 ──► [漂流海·首次空状态引导]
   └─ 拒绝 ──► 降级:仅按兴趣+MBTI匹配 ──► [漂流海]
```

### 2.2 写信投递

```
[我的信件] ──点 FAB"投递漂流瓶"──► [写信编辑器]
   │
   ├─ 选信纸样式(MVP 2–3 款) / 写正文 / (可选)留一句文字标签
   │
   ▼ 点"封缄寄出"
[投递确认弹层] "这封信将漂向远方，途中无法召回。确认投递？"
   │ 确认
   ▼
[AI 审核中] "邮局正在分拣……" (秒级)
   ├─ 通过 ──► [在途中] 状态卡 → 信鸽动画启动(按距离粗档:近=信鸽快/远=车马慢)
   │            └─ 到时 ──► 漂入海面(对他人可打捞)
   │
   └─ 拦截 ──► [被拒页] 说明原因(高危/联系方式检测)
                ├─ 可修改重投(回编辑器，保留草稿)
                └─ 严重违规 → 记录+守护提示
```

### 2.3 打捞 → 预览 → 拆封

```
[漂流海·海面] ──点"打捞"(消耗1次/3)──► 抛竿动画
   │
   ▼
[打捞预览卡] (10 分钟预览锁倒计时)
   │ 仅显示:半张文字名片(昵称+MBTI标签+1-2兴趣标签+模糊距离)
   │         + 信件前 2–3 行 + 文字情绪标签(不露照片)
   │
   ├─► "放回海面" ──► 信回池(本次打捞次数已消耗，不退)
   │
   ├─► 10 分钟内未操作 ──► 自动放回 + 轻提示
   │
   └─► "拆开火漆"(消耗1次拆封/1)
          ▼
       [拆封仪式动画] (火漆裂开)
          ▼
       [拆封读信页] 全文展开 + 完整文字名片(仍不强制露照片)
          │ 信进入"暂离池"，对其他人不可打捞
          │ 启动 7 天回信窗口(潮汐倒计时)
          ▼
       [回信页] 入口
```

### 2.4 回信成笔友

```
[拆封读信页] ──点"提笔回信"──► [回信页]
   │ (7天潮汐倒计时常驻顶部)
   ▼ 写回信 → AI审核 → 寄出
[回信投递成功]
   │
   ├─ 在 7 天窗口内成功回信 ──► ✦结缘✦ ──► 双方进入[笔友信匣]
   │       (往来保留在途延迟，不变即时)
   │
   └─ 7 天内未回信(任一方) ──► [窗口超时] 信回海面重新漂流
                                 原拆封者收到温和提示，关系不建立
```

### 2.5 笔友信匣往来

```
[笔友信匣·列表] ──点某笔友──► [笔友往来会话]
   │ 显示历史往来信(气泡/信笺样式)，按时间顺序
   │ 永不显示"已读"
   ▼ 点"回一封"──► [写信:笔友模式] → AI审核 → 寄出
        └─ 在途延迟(粗档)──► 到时落入对方信匣，本方显示"信鸽已出发"
   │
   ├─ 长按笔友/菜单 ──► 举报 / 拉黑(退回邮局) / 备注
   └─ 拉黑后:会话归档，不再往来
```

## 4. 边界态设计（空 / 加载 / 错误 / 被拒 / 超时）

> 统一原则：边界态也讲世界观、不甩冷冰冰的系统语；给出明确下一步。

**空状态（Empty）**
| 场景 | 插画 | 主文案 | 副文/按钮 |
|---|---|---|---|
| 漂流海无可捞信 | 平静海面 | 「此刻海面平静」 | 「稍后再来碰碰运气」 |
| 我的信件无信 | 空信箱 | 「你还没寄出第一封信」 | [投递漂流瓶] |
| 笔友信匣无笔友 | 一只待命信鸽 | 「还没有人与你结缘」 | 「去漂流海打捞一封吧」[去漂流海] |
| 在途无信 | — | 「暂无在途的信」 | — |

**加载态（Loading，慢社交故意留白）**
- 打捞抛竿：1–2s 抛线动画，文案「正在打捞……」。
- AI 审核分拣：全屏柔光遮罩 + 信封旋转，「邮局正在分拣，请稍候」。
- 在途进度：非 spinner，而是信鸽逐帧前进（粗档）。
- 列表加载：信纸骨架屏（信笺横线占位），不用生硬灰块。

**错误态（Error）**
| 场景 | 文案 | 操作 |
|---|---|---|
| 网络断开 | 「邮局暂时联系不上」 | [重试] |
| 提交失败 | 「这封信没能寄出去」 | [再寄一次]（保留草稿） |
| 资源失效(信已被结缘/回池) | 「这封信已经有了归宿」 | [返回海面] |
| 并发拆封冲突(锁竞争) | 「这封信刚被另一位旅人拆开了」 | 自动退回，本次拆封次数返还 + 提示 |

> 注：拆封并发冲突对应 Redis 原子锁 + DB 乐观锁失败，前端必须有此态，并明确"次数返还"以免用户损失。

**被拒态（AI 审核拦截）**
```
┌─────────────────────────────┐
│ 插画: 退回的信封 + 火漆裂痕    │
│ 标题「这封信未能通过分拣」     │
│ 原因(分级文案,不暴露规则细节): │
│  · 含违规内容 →「信中有不宜    │
│     寄出的内容」               │
│  · 疑似联系方式 →「请勿在信中  │
│     留下站外联系方式」         │
│ 操作: [修改后重投] / [放弃]    │
│ 守护提示(未成年/严重):记录留痕 │
└─────────────────────────────┘
```

**超时态（7 天回信窗口流失）**
| 视角 | 文案 |
|---|---|
| 拆封方未回信超时 | 「潮汐已落，这封信重新漂回了海面」 |
| 回信方等待对方超时 | 「这次相遇没有续上，信已回到漂流海」 |
| 预览锁 10 分钟超时 | Toast「你犹豫太久，信漂走了」 |

**配额耗尽态**：入口按钮统一灰态 + 「明日潮汐再启」，附下次重置的模糊提示（"约 N 小时后"，不给精确秒）。

## 5. 慢社交交互节奏与动效要点（GSAP）

**核心理念**：用"延迟、留白、仪式"对抗即时社交的焦虑感；反馈刻意"去人格化、去效率化"。

1. **在途进度（车马 / 信鸽）**
   - 真实地理距离 → 粗档时延（MVP 固定档：近≈数小时、中≈1–2天、远≈3天+）。
   - 视觉：信鸽逐帧飞行 / 车马行进，进度条以"路程"而非"百分比"呈现。
   - 严禁实时刷新秒级进度；进入页面才推进一帧，强化"慢"。

2. **拆封仪式（仪式感峰值）**
   - 火漆封印按压裂开（长按 0.6s 触发更有"动手"感）→ 信纸展开（GSAP `power2.out` 缓动 + 轻微纸张抖动）。
   - 配可选触感反馈（PWA Vibration API）。
   - 拆封前的"10 分钟犹豫锁"用缓慢收缩的封蜡进度环表达，制造珍惜感。

3. **结缘动画（关系确立的唯一高光）**
   - 双方火漆印章相向合拢 → 闪光 →「✦ 结缘 ✦」。这是 MVP 里最重的正反馈，要做足。

4. **去人格化反馈（硬约束的动效表达）**
   - 无"已读"动画、无"对方在线"绿点、无"正在输入"省略号。
   - 信送达对方：本方只显示"信鸽已抵达"，绝不显示对方是否查看。
   - 时间用潮汐/漂泊天数等模糊隐喻替代精确时间戳。

5. **打捞节奏**
   - 抛竿故意 1–2s 慢动作，强调"碰运气"而非"刷信息流"；不做无限下拉，一次一捞，配额硬限。

6. **全局动效约束（性能 + 无障碍）**
   - 一律走 transform/opacity，避免触发 layout（参见 GSAP 性能实践）。
   - 必须支持 `prefers-reduced-motion`：降级为淡入淡出，仪式动画缩短，保证可用。
