# 《信逢 Inkling · MVP 数据库设计（PostgreSQL 16）》

> 版本：v1.0（细化设计阶段，DDL 可直接执行）· 日期：2026-06-14
> 目标库：PostgreSQL 16 + PostGIS（仅用于 GeoHash 前缀检索，**不落原始经纬度**）+ pgvector（演进预留，MVP 不建向量索引）
> 命名约定：表名/字段名 `snake_case`；状态/枚举用原生 `ENUM`（`CREATE TYPE`）；时间统一 `TIMESTAMPTZ`（UTC 存储）；金额/计数用整型；标签/画像用 `JSONB`。
> 标注规则：每个表/字段在注释中标注 **[MVP]** 或 **[演进预留]**。演进预留字段允许 NULL 且不参与 MVP 业务逻辑，仅为避免将来迁移痛。

---

## 0. 设计总览与铁律

| 铁律 | 落地手段 |
|---|---|
| 地理只存 GeoHash 前 5 位（±2.4km），原始经纬度内存即弃 | 仅 `geohash5 CHAR(5)`，**无** lat/lng 列；PostGIS 仅用于前缀范围检索 |
| 拆封并发用 Redis 原子锁 + DB 乐观锁双保险 | `letters.version INT` + CAS 更新；状态机迁移走 `WHERE status=? AND version=?` |
| 配额按 user × date 防超发 | `daily_quotas` 复合主键 `(user_id, quota_date)` |
| 打捞去重（同人不重复捞同信） | `fishing_records` 唯一约束 `(user_id, letter_id)` |
| 永不显示"已读" | 数据层**不存** read/seen 字段；预览快照只存可公开的去人格化片段 |
| 未成年数据最小化 | 出生只存**年月**（`birth_year`/`birth_month`），不存精确日；审核命中证据脱敏存储 |
| 留存与删除（GDPR/COPPA） | 软删 `deleted_at` + 物理删除作业；`data_deletion_requests` 留痕 |

## 1. ER 关系概述（文字）

**核心实体与关系：**

- **users（账号）** 1—1 **user_profiles（资料：MBTI/兴趣/偏好/地理/年龄档/守护标志）**。账号承载认证与年龄档，资料承载匹配特征。
- **users** 1—N **parental_consents（家长同意记录）**：未成年/需家长同意法域下，一个未成年账号可能有多条同意/撤回事件（审计链）。
- **users** 1—N **letters（信件）** 作为作者（`author_id`）。信件是状态机主体，从 `draft → reviewing → in_transit → drifting → previewing → unsealed → (paired | re_drifting)`。
- **letters** 1—1 **delivery_tasks（递送任务）**：每封进入在途的信对应一条递送计时任务（RabbitMQ 延时队列的 DB 镜像）。
- **letters** 1—N **fishing_records（打捞记录）**：一封信生命周期内可被多次打捞（放回后重漂），但 `(user_id, letter_id)` 唯一——同一人不可重复捞同一封。
- **fishing_records** 1—1 **preview_snapshots（预览快照）**：打捞瞬间冻结的"半张名片 + 前几行 + 文字标签"，去人格化、对外可见。
- **fishing_records** 0/1—1 **unseal_records（拆封记录）**：一次打捞至多产生一次拆封；拆封启动 7 天回信窗口。
- **unseal_records** 0/1—1 **pen_pal_relations（笔友关系）**：7 天内成功回信 → 结缘 → 建立笔友关系（双向，存一行 + 规范化 `user_low/user_high`）。
- **pen_pal_relations** 1—N **correspondences（往来书信）**：结缘后双方往来，保留在途延迟。
- **审核/安全横切**：**content_reviews（审核记录）** 关联到 `letters`/`correspondences`（多态目标）；**reports（举报）**、**blocks（拉黑）**、**penalties（处罚）** 关联到 `users`。
- **配额**：**daily_quotas** 以 `(user_id, quota_date)` 记录当日 投/捞/拆 用量。

```
users ──1:1── user_profiles
  │
  ├──1:N── parental_consents          (未成年合规)
  ├──1:N── letters (author)           ──1:1── delivery_tasks
  │           │
  │           └──1:N── fishing_records ──1:1── preview_snapshots
  │                        │
  │                        └──0/1── unseal_records ──0/1── pen_pal_relations ──1:N── correspondences
  │
  ├──1:N── daily_quotas
  ├──1:N── reports / blocks / penalties
  └──1:N── data_deletion_requests
content_reviews ──多态──> (letters | correspondences)
```

## 2. 扩展与枚举类型（CREATE EXTENSION / CREATE TYPE）

```sql
-- ============================================================
-- 扩展
-- ============================================================
CREATE EXTENSION IF NOT EXISTS pgcrypto;   -- gen_random_uuid()
CREATE EXTENSION IF NOT EXISTS postgis;     -- GeoHash 前缀/邻接检索（不存原始经纬度）
CREATE EXTENSION IF NOT EXISTS pg_trgm;     -- 文本审核辅助检索（可选）
-- CREATE EXTENSION IF NOT EXISTS vector;   -- [演进预留] pgvector 画像召回，MVP 不启用

-- ============================================================
-- 枚举类型
-- ============================================================

-- 信件状态机 [MVP]
-- draft草稿 → reviewing审核中 → in_transit在途 → drifting漂流海(可打捞)
-- → previewing被打捞(10min预览锁) → unsealed已拆封(暂离池,7天回信窗)
-- → paired已结缘 / re_drifting超时回池重漂 / rejected审核拒 / withdrawn系统撤回
CREATE TYPE letter_status AS ENUM (
  'draft', 'reviewing', 'in_transit', 'drifting',
  'previewing', 'unsealed', 'paired', 're_drifting',
  'rejected', 'withdrawn'
);
COMMENT ON TYPE letter_status IS '[MVP] 信件状态机枚举';

-- 审核风险等级 [MVP]
-- pass通过 / low低危(放行+记录) / mid中危(降权/限制) / high高危(秒级拦截) / block直接封禁内容
CREATE TYPE review_risk_level AS ENUM ('pass', 'low', 'mid', 'high', 'block');
COMMENT ON TYPE review_risk_level IS '[MVP] 机器审核风险等级';

-- 审核命中类别 [MVP]
CREATE TYPE review_category AS ENUM (
  'clean',            -- 无命中
  'contact_info',     -- 联系方式(手机/微信/邮箱/社交账号)检测
  'sexual',           -- 色情低俗
  'sexual_minor',     -- 涉未成年性相关(零容忍)
  'grooming',         -- 诱导线下/索取私密信息(零容忍)
  'violence',         -- 暴力血腥
  'harassment',       -- 骚扰辱骂
  'self_harm',        -- 自伤自杀(转危机干预)
  'scam_spam',        -- 诈骗/广告/导流
  'pii',              -- 泄露真实身份信息
  'other'
);
COMMENT ON TYPE review_category IS '[MVP] 审核命中类别(可多值，存数组)';

-- 处罚类型 [MVP]
CREATE TYPE penalty_type AS ENUM (
  'warn',             -- 警告
  'downrank',         -- 匹配降权
  'mute',             -- 禁言(禁投递/禁回信) 一段时间
  'feature_limit',    -- 功能限制(如禁打捞)
  'shadow_limit',     -- 影子限制(降低被打捞概率)
  'suspend',          -- 暂停账号
  'ban',              -- 永久封禁
  'guardian_lock'     -- 强制锁定守护模式(未成年保护)
);
COMMENT ON TYPE penalty_type IS '[MVP] 处罚类型';

-- 年龄档 [MVP] —— 与安全文档一致
-- u13:<13(默认拒绝/需VPC) t1317:13-17(强制守护) a18:>=18 unknown:不确定(按未成年兜底)
CREATE TYPE age_tier AS ENUM ('u13', 't1317', 'a18', 'unknown');
COMMENT ON TYPE age_tier IS '[MVP] 年龄分档；unknown 一律按未成年人兜底保护';

-- 年龄保障等级 [MVP]
CREATE TYPE age_assurance_level AS ENUM (
  'self_declared',    -- 自声明出生年月(基线)
  'facial_estimate',  -- AI面部年龄估计(估值即弃)
  'card_check',       -- 信用卡校验
  'third_party_id',   -- 第三方身份/年龄验证
  'parental_verified' -- 家长同意已验证(VPC完成)
);
COMMENT ON TYPE age_assurance_level IS '[MVP] 年龄保障强度，决定可否进成年开放池/解除守护';

-- 递送工具 [MVP] —— 按真实地理距离决定快慢
CREATE TYPE delivery_vehicle AS ENUM ('pigeon', 'horse');  -- pigeon信鸽(近/快) horse车马(远/慢)
COMMENT ON TYPE delivery_vehicle IS '[MVP] 递送工具，按 GeoHash 距离粗档决定';

-- 递送任务状态 [MVP]
CREATE TYPE delivery_status AS ENUM ('scheduled', 'delivered', 'cancelled');
COMMENT ON TYPE delivery_status IS '[MVP] 递送计时任务状态';

-- 自报 MBTI 可信度 [MVP]
CREATE TYPE mbti_confidence AS ENUM ('unknown', 'unsure', 'confident', 'verified');
COMMENT ON TYPE mbti_confidence IS '[MVP] 自报可信度；verified 为演进(mini-test校准)预留取值';

-- 账号状态 [MVP]
CREATE TYPE account_status AS ENUM ('active', 'invisible', 'suspended', 'banned', 'pending_consent', 'deleted');
COMMENT ON TYPE account_status IS '[MVP] 账号状态；invisible=闭关隐身；pending_consent=待家长同意';

-- 举报状态 [MVP]
CREATE TYPE report_status AS ENUM ('open', 'reviewing', 'actioned', 'dismissed');
COMMENT ON TYPE report_status IS '[MVP] 举报处理状态';

-- 笔友关系状态 [MVP]
CREATE TYPE relation_status AS ENUM ('active', 'archived', 'blocked');
COMMENT ON TYPE relation_status IS '[MVP] 笔友关系状态；blocked=拉黑归档';

-- 同意事件类型 [MVP]
CREATE TYPE consent_event AS ENUM ('granted', 'revoked', 'expired', 'updated');
COMMENT ON TYPE consent_event IS '[MVP] 家长同意事件类型';

-- 数据删除请求状态 [MVP]
CREATE TYPE deletion_status AS ENUM ('requested', 'processing', 'completed', 'cancelled');
COMMENT ON TYPE deletion_status IS '[MVP] GDPR/COPPA 删除请求状态';
```

## 3. 完整 DDL（建表）

### 3.1 用户与认证

```sql
-- ============================================================
-- users 账号与认证 [MVP]
-- ============================================================
CREATE TABLE users (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  public_id         UUID NOT NULL DEFAULT gen_random_uuid(),       -- 对外暴露ID(不暴露自增id)
  -- 认证标识(海外优先邮箱/三方OAuth；手机号可空)
  email             CITEXT,                                        -- 大小写不敏感邮箱(需 citext 扩展，或用 TEXT+lower索引)
  phone             VARCHAR(32),                                   -- E.164，海外可空
  password_hash     TEXT,                                          -- 仅密码登录时有；OAuth 用户可空
  oauth_provider    VARCHAR(20),                                   -- 'apple' | 'google' | NULL
  oauth_subject     VARCHAR(191),                                  -- 三方 sub
  -- 年龄与合规(准入前置)
  age_tier          age_tier NOT NULL DEFAULT 'unknown',           -- [MVP] 年龄分档
  birth_year        SMALLINT,                                      -- [MVP] 仅存年(数据最小化)
  birth_month       SMALLINT CHECK (birth_month BETWEEN 1 AND 12), -- [MVP] 仅存月，不存日
  age_assurance     age_assurance_level NOT NULL DEFAULT 'self_declared', -- [MVP] 年龄保障等级
  age_locked_at     TIMESTAMPTZ,                                   -- [MVP] 年龄档锁定时刻(进入未成年区间后不可前端自助上调)
  jurisdiction      VARCHAR(8),                                    -- [MVP] 法域代码(声明居住地: 'HK''TW''DE''US'..) 决定走哪套合规
  -- 状态与守护
  status            account_status NOT NULL DEFAULT 'active',      -- [MVP] 账号状态
  is_invisible      BOOLEAN NOT NULL DEFAULT FALSE,                -- [MVP] 闭关隐身
  -- 审计
  last_login_at     TIMESTAMPTZ,                                   -- 内部审计用，绝不对外展示(不显示"最后活跃")
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  deleted_at        TIMESTAMPTZ,                                   -- [MVP] 软删；配合物理删除作业
  CONSTRAINT uq_users_public_id UNIQUE (public_id),
  CONSTRAINT uq_users_oauth UNIQUE (oauth_provider, oauth_subject),
  CONSTRAINT ck_users_auth_present CHECK (
    email IS NOT NULL OR phone IS NOT NULL OR oauth_subject IS NOT NULL
  )
);
COMMENT ON TABLE  users IS '[MVP] 账号与认证主表';
COMMENT ON COLUMN users.public_id  IS '[MVP] 对外稳定标识，API/前端只暴露此ID';
COMMENT ON COLUMN users.birth_year IS '[MVP] 仅存出生年(数据最小化，不存精确日期)';
COMMENT ON COLUMN users.age_tier   IS '[MVP] 年龄档；unknown 按未成年兜底保护';
COMMENT ON COLUMN users.jurisdiction IS '[MVP] 法域(声明居住地)，与设备/IP冲突时取更严';
COMMENT ON COLUMN users.last_login_at IS '[MVP] 仅内部审计；严禁对外暴露(去人格化:不显示最后活跃)';
```

> 注：`CITEXT` 需要 `CREATE EXTENSION citext;`。若不引入该扩展，可改 `email TEXT` 并在 `lower(email)` 上建唯一索引（见 §4）。

### 3.2 用户资料（自报 MBTI / 兴趣标签 / 偏好滑杆 / GeoHash / 年龄分级 / 守护模式标志）

```sql
-- ============================================================
-- user_profiles 用户资料(匹配特征 + 守护标志) [MVP]
-- ============================================================
CREATE TABLE user_profiles (
  user_id           BIGINT PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  -- 文字名片(去人格化，无真人照片字段)
  nickname          VARCHAR(40) NOT NULL,                          -- [MVP] 笔名(需审核)
  card_bio          VARCHAR(200),                                  -- [MVP] 文字名片简介(打捞预览露半张)
  avatar_kind       VARCHAR(20),                                   -- [MVP] 仅"文字/插画头像"类别标识；不存真人照片URL
  -- 自报 MBTI
  mbti_type         CHAR(4),                                       -- [MVP] 自报型号 如 'INFP'，可空=未填
  mbti_conf         mbti_confidence NOT NULL DEFAULT 'unknown',    -- [MVP] 自报可信度，作为打分系数
  mbti_note         VARCHAR(30),                                   -- [MVP] 一句话说明，纯展示不入算法
  mbti_test_score   JSONB,                                         -- [演进预留] mini-test 四维连续值 {ei,sn,tf,jp:-100..100}
  -- 兴趣标签(受控词表 id 集合)
  interest_tags     JSONB NOT NULL DEFAULT '[]'::jsonb,            -- [MVP] 形如 [12,34,56]，至少3个(应用层校验)
  -- 偏好滑杆 0~100
  pref_similarity   SMALLINT NOT NULL DEFAULT 50 CHECK (pref_similarity BETWEEN 0 AND 100), -- [MVP] 相似↔荣格互补
  pref_distance     SMALLINT NOT NULL DEFAULT 50 CHECK (pref_distance  BETWEEN 0 AND 100),  -- [MVP] 就近↔远方
  pref_serendipity  SMALLINT NOT NULL DEFAULT 50 CHECK (pref_serendipity BETWEEN 0 AND 100),-- [MVP] 偶遇强度
  -- 地理(只存 GeoHash 前5位 ±2.4km，不存原始经纬度)
  geohash5          CHAR(5),                                       -- [MVP] GeoHash 前5位；NULL=未授权(降级为兴趣+MBTI匹配)
  geo_authorized    BOOLEAN NOT NULL DEFAULT FALSE,                -- [MVP] 是否授权地理
  geo_updated_at    TIMESTAMPTZ,                                   -- [MVP] geohash 更新时间(粗，用于过期刷新)
  -- 画像向量(演进)
  profile_vector    JSONB,                                         -- [演进预留] 行为画像向量(MVP不用，将来迁 vector 列)
  -- 守护模式标志(未成年保护)
  guardian_mode     BOOLEAN NOT NULL DEFAULT FALSE,               -- [MVP] 守护模式开关(未成年/unknown 默认TRUE)
  guardian_locked   BOOLEAN NOT NULL DEFAULT FALSE,              -- [MVP] 是否锁定(本人不可关，需更高年龄保障)
  female_safeguard  BOOLEAN NOT NULL DEFAULT FALSE,              -- [MVP] 女性账号默认更严守护
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  CONSTRAINT ck_mbti_type CHECK (
    mbti_type IS NULL OR mbti_type ~ '^[EI][SN][TF][JP]$'
  )
);
COMMENT ON TABLE  user_profiles IS '[MVP] 用户资料与匹配特征；无真人照片字段';
COMMENT ON COLUMN user_profiles.mbti_type      IS '[MVP] 自报16型，正则约束 E/I·S/N·T/F·J/P';
COMMENT ON COLUMN user_profiles.mbti_conf      IS '[MVP] 自报可信度，打分时作 conf_factor 系数';
COMMENT ON COLUMN user_profiles.mbti_note      IS '[MVP] 仅展示，不参与匹配算法';
COMMENT ON COLUMN user_profiles.interest_tags  IS '[MVP] 兴趣标签id数组(JSONB)，GIN索引加速 Jaccard 召回';
COMMENT ON COLUMN user_profiles.geohash5       IS '[MVP] 仅GeoHash前5位(±2.4km)；绝不存原始经纬度';
COMMENT ON COLUMN user_profiles.guardian_mode  IS '[MVP] 守护模式；未成年/unknown 强制开启';
COMMENT ON COLUMN user_profiles.guardian_locked IS '[MVP] 守护锁定，需通过更高年龄保障才可降级';
COMMENT ON COLUMN user_profiles.profile_vector IS '[演进预留] 画像向量，MVP不用，pgvector上线后迁移';
```

### 3.3 家长同意记录（VPC 审计链）

```sql
-- ============================================================
-- parental_consents 家长同意记录(VPC) [MVP-合规强制]
-- ============================================================
CREATE TABLE parental_consents (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  user_id           BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE, -- 未成年账号
  event             consent_event NOT NULL,                        -- granted/revoked/expired/updated
  method            age_assurance_level,                           -- 验证方法(card_check/third_party_id...)
  parent_email_hash TEXT,                                          -- [MVP] 家长邮箱哈希(最小化，不存明文)
  -- 分项同意(COPPA/GDPR-K separate consent)
  scope_account     BOOLEAN NOT NULL DEFAULT FALSE,                -- ①账号创建与基础书信
  scope_third_party BOOLEAN NOT NULL DEFAULT FALSE,                -- ②第三方共享(广告/分析)：MVP对未成年恒为FALSE
  scope_ai_training BOOLEAN NOT NULL DEFAULT FALSE,                -- ③AI训练：未成年恒为FALSE(承诺永不入训练集)
  evidence_ref      TEXT,                                          -- 验证凭证引用(脱敏存储指针，非原件)
  jurisdiction      VARCHAR(8),                                    -- 适用法域
  occurred_at       TIMESTAMPTZ NOT NULL DEFAULT now(),            -- [MVP] 事件时间戳(可审计)
  expires_at        TIMESTAMPTZ,                                   -- 同意有效期(到期需复验)
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  CONSTRAINT ck_minor_no_ai_train CHECK (scope_ai_training = FALSE) -- [MVP] 强约束:未成年数据永不入训练集
);
COMMENT ON TABLE  parental_consents IS '[MVP] 家长同意(VPC)审计链：带时间戳/方法/结果，可应监管要求导出';
COMMENT ON COLUMN parental_consents.parent_email_hash IS '[MVP] 家长邮箱仅存哈希(数据最小化)';
COMMENT ON COLUMN parental_consents.scope_ai_training IS '[MVP] 恒FALSE：未成年人数据永不用于AI训练';
COMMENT ON COLUMN parental_consents.evidence_ref      IS '[MVP] 验证凭证指针(脱敏)，不存身份原件';
```

### 3.4 信件（状态机 + pool_visible_at + expire_at + 乐观锁 version）

```sql
-- ============================================================
-- letters 信件(状态机主体) [MVP]
-- ============================================================
CREATE TABLE letters (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  public_id         UUID NOT NULL DEFAULT gen_random_uuid(),
  author_id         BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  status            letter_status NOT NULL DEFAULT 'draft',        -- [MVP] 状态机
  version           INTEGER NOT NULL DEFAULT 0,                    -- [MVP] 乐观锁；状态迁移用 CAS
  -- 内容
  paper_style       SMALLINT NOT NULL DEFAULT 1,                   -- [MVP] 信纸样式(MVP 2-3款)
  body              TEXT NOT NULL,                                 -- [MVP] 正文
  body_preview      VARCHAR(300),                                  -- [MVP] 前几行(预览用，去敏后冗余)
  emotion_tag       VARCHAR(40),                                   -- [MVP] 文字情绪标签(不露照片)
  -- 作者特征快照(写时冻结，防作者改资料后历史信错乱；供精排免回查)
  snap_mbti_type    CHAR(4),                                       -- [MVP] 快照:作者MBTI
  snap_mbti_conf    mbti_confidence,                               -- [MVP] 快照:可信度
  snap_interest_tags JSONB NOT NULL DEFAULT '[]'::jsonb,           -- [MVP] 快照:兴趣标签
  snap_geohash5     CHAR(5),                                       -- [MVP] 快照:GeoHash5(召回用)
```

## 4. 关键索引（GIN / GeoHash 前缀 / 复合 / 唯一约束）

```sql
-- ============================================================
-- 用户与认证
-- ============================================================
-- 邮箱唯一(若用 TEXT 而非 citext，用表达式唯一索引)
CREATE UNIQUE INDEX uq_users_email_lower ON users (lower(email)) WHERE email IS NOT NULL;
CREATE UNIQUE INDEX uq_users_phone       ON users (phone)        WHERE phone IS NOT NULL;
-- 仅检索未软删账号
CREATE INDEX ix_users_status ON users (status) WHERE deleted_at IS NULL;

-- ============================================================
-- 用户资料:兴趣标签 GIN + 地理前缀
-- ============================================================
-- [MVP] 兴趣标签 JSONB GIN：加速 Jaccard 召回(@>、?| 等)
CREATE INDEX gin_profiles_interest ON user_profiles USING GIN (interest_tags jsonb_path_ops);
-- [MVP] GeoHash 前缀检索：前3位粗就近召回(text_pattern_ops 支持 LIKE 'xxx%' 前缀走索引)
CREATE INDEX ix_profiles_geohash_prefix ON user_profiles (geohash5 text_pattern_ops) WHERE geohash5 IS NOT NULL;
-- [MVP] 守护模式快速过滤(同龄池隔离)
CREATE INDEX ix_profiles_guardian ON user_profiles (guardian_mode) WHERE guardian_mode = TRUE;
-- MBTI 召回(可选)
CREATE INDEX ix_profiles_mbti ON user_profiles (mbti_type) WHERE mbti_type IS NOT NULL;

-- ============================================================
-- 信件:召回核心复合索引 (status + pool_visible_at)
-- ============================================================

CREATE INDEX ix_letters_expire ON letters (status, expire_at) WHERE status = 'unsealed';

-- ============================================================
-- 拆封:回信窗口扫描
-- ============================================================
CREATE INDEX ix_unseal_deadline ON unseal_records (reply_deadline)
  WHERE is_replied = FALSE AND is_expired = FALSE;

-- ============================================================
-- 笔友与往来
-- ============================================================
-- 双向唯一已在表内 uq_relation_pair
CREATE INDEX ix_relation_user_low  ON pen_pal_relations (user_low,  status, last_letter_at DESC);
CREATE INDEX ix_relation_user_high ON pen_pal_relations (user_high, status, last_letter_at DESC);
-- 往来按关系 + 时间
CREATE INDEX ix_corr_relation ON correspondences (relation_id, sent_at DESC) WHERE deleted_at IS NULL;
-- 收件箱:未送达扫描(在途到时落库)
CREATE INDEX ix_corr_arrive ON correspondences (arrive_at) WHERE is_arrived = FALSE;

-- ============================================================
-- 递送任务:延时触发扫描(MQ兜底对账)
-- ============================================================
CREATE INDEX ix_delivery_due ON delivery_tasks (scheduled_at)
  WHERE status = 'scheduled';
CREATE UNIQUE INDEX uq_delivery_mq ON delivery_tasks (mq_message_id) WHERE mq_message_id IS NOT NULL;
CREATE INDEX ix_delivery_target ON delivery_tasks (target_type, target_id);

-- ============================================================

-- ============================================================
CREATE INDEX ix_reviews_target ON content_reviews (target_type, target_id);

-- [MVP] 高危/涉未成年优先排查
CREATE INDEX ix_reviews_high_risk ON content_reviews (risk_level, decided_at DESC)
  WHERE risk_level IN ('high','block') OR is_minor_context = TRUE;
CREATE INDEX gin_reviews_categories ON content_reviews USING GIN (categories jsonb_path_ops);

CREATE INDEX ix_penalties_active ON penalties (user_id, is_active) WHERE is_active = TRUE;
CREATE INDEX ix_reports_open ON reports (status, created_at) WHERE status IN ('open','reviewing');
CREATE INDEX ix_reports_reported ON reports (reported_user_id, created_at DESC);
-- blocks 唯一已在表内；反查"谁拉黑了我"
CREATE INDEX ix_blocks_blocked ON blocks (blocked_id);

CREATE INDEX ix_deletion_status ON data_deletion_requests (status, requested_at) WHERE status IN ('requested','processing');
```

## 5. 并发与一致性说明

### 5.1 拆封竞态：Redis 原子锁 + DB 乐观锁 version CAS（双保险）

打捞预览阶段一封信仍在 `drifting` 池，多个用户可能同时点"拆开火漆"。拆封必须保证**全局只有一人成功**，且与"配额扣减、状态迁移、暂离池"原子一致。

**第一道（Redis 原子锁）**：以 `lock:unseal:{letter_id}` 为键 `SET NX PX 5000` 抢锁，抢到才进入 DB 事务，避免无谓的 DB 写竞争。

**第二道（DB 乐观锁 CAS）**：状态迁移用条件更新，命中 0 行即判定竞态失败（他人已拆/已变更）：

```sql
-- 拆封状态迁移（在事务内）：drifting/previewing -> unsealed
UPDATE letters
   SET status         = 'unsealed',
       version        = version + 1,
       unsealed_at    = now(),
       expire_at      = now() + INTERVAL '7 days'
 WHERE id      = :letter_id
   AND status IN ('drifting','previewing')   -- 只允许从可拆状态迁移
   AND version = :expected_version;          -- 乐观锁 CAS
-- 影响行数 = 0  → 竞态失败，回滚事务、释放Redis锁、提示"这封信刚被别人拆走了"
-- 影响行数 = 1  → 成功，继续写 unseal_records、扣 daily_quotas、写 delivery_tasks(repool 7d)
```

**为何双保险**：Redis 锁解决高频热点的"惊群"与性能；DB version CAS 是**最终事实裁决**，即便 Redis 锁因过期/宕机失效，CAS 也能在数据库层保证唯一成功。两者缺一不可。

### 5.2 配额防超发

- 实时计数走 Redis（`INCR` + 当日 TTL），扣减与业务动作在同一逻辑事务内；
- DB `daily_quotas` 复合主键 `(user_id, quota_date)` 作为**落盘对账与兜底**，并发首次写用 `INSERT ... ON CONFLICT (user_id, quota_date) DO UPDATE`，天然避免重复行：

```sql
INSERT INTO daily_quotas (user_id, quota_date, fish_used)
VALUES (:uid, CURRENT_DATE, 1)
ON CONFLICT (user_id, quota_date)
DO UPDATE SET fish_used = daily_quotas.fish_used + 1,
              updated_at = now()
WHERE daily_quotas.fish_used < daily_quotas.fish_limit   -- 超限则不更新
RETURNING fish_used;
-- 无 RETURNING 行 → 配额已耗尽
```

### 5.3 打捞去重

`fishing_records` 唯一约束 `(user_id, letter_id)`。召回时即排除该用户已捞过的信；并发重复打捞由唯一约束兜底（`INSERT ... ON CONFLICT DO NOTHING`，0 行即"已捞过"）。

### 5.4 递送/回池可靠性

`delivery_tasks` 作为 RabbitMQ 延时队列的 **DB 镜像**：
- MQ 消息正常触发 → 按 `mq_message_id` 幂等处理（唯一索引防重复送达/回池）；
- MQ 丢消息 → 定时扫描 `ix_delivery_due`（`status='scheduled' AND scheduled_at<=now()`）兜底补偿。

### 5.5 状态机迁移统一规范

所有信件状态迁移一律走 `WHERE status IN (合法前驱) AND version=?` 的 CAS 模式，`version+1`。禁止裸 `UPDATE status`。回池迁移示例：

```sql
UPDATE letters
   SET status='re_drifting', version=version+1, pool_visible_at=now()
 WHERE id=:id AND status='unsealed' AND expire_at<=now() AND version=:v;
```

## 6. 数据保护落地（合规映射）

| 要求 | 数据库落地 |
|---|---|
| **地理只存 GeoHash 前 5 位** | 全库**无** lat/lng 列；仅 `geohash5 CHAR(5)`（±2.4km）。原始经纬度在应用内存计算 GeoHash 后即弃，不进任何表、不进日志。预览只输出 `fuzzy_distance` 文案。 |
| **未成年数据最小化** | 出生只存 `birth_year`/`birth_month`（无精确日）；家长侧仅存 `parent_email_hash`（哈希，非明文）；`evidence_ref`/`evidence_masked` 只存脱敏指针，不存身份原件；`parental_consents.scope_ai_training` 硬约束恒 `FALSE`（未成年数据永不入训练集）。 |
| **保守兜底（fail-safe to minor）** | `age_tier` 默认 `unknown`，`unknown` 在召回/匹配层一律按未成年隔离；`user_profiles.guardian_mode` 对 t1317/unknown 默认 TRUE 且 `guardian_locked`。 |
| **gate-before-collection** | `users.status='pending_consent'` 表示未完成年龄分流/家长同意，此状态下不写 `user_profiles` 匹配特征、不进任何召回池。 |
| **审核记录脱敏** | `content_reviews` 不存原文，仅存 `categories` + `evidence_masked`（掩码/哈希）+ 模型版本，满足申诉与监管导出但不二次泄露敏感内容。 |
| **永不显示"已读"** | 结构层面**不设** read/seen/online/last_active 字段；`users.last_login_at` 标注"仅内部审计、严禁对外"。 |
| **留存与删除** | 全主表带 `deleted_at` 软删；`data_deletion_requests` 留痕（用户/家长/监管发起）；物理删除作业按法域留存期清理软删数据；家长撤回同意（`parental_consents.event='revoked'`）触发账号冻结 + 删除流程。 |
| **可审计** | `parental_consents`、`content_reviews`、`penalties`、`data_deletion_requests` 均带时间戳与操作来源，满足"auditable, logged, timestamped, available on request"。 |
