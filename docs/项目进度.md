## 4. 已实现 ✅（脚手架范围）

- **核心循环全链路**：注册(年龄门控+未成年守护) → 自报 MBTI/兴趣 → 写信(审核→在途) → 漂流海打捞(10 分钟预览锁) → 拆封 → 7 天内回信结缘成笔友 → 笔友信匣往来
- **并发安全**：拆封 = Redis 锁 + DB 乐观锁(version CAS)，杜绝一封信被两人拆开
- **时间驱动状态机**：`delivery.scheduler` 轮询处理 入池/预览锁回收/7天超时回池/笔友信送达/漂流归档
- **配额**：每日 1投/3捞/1拆 原子扣减
- **匹配**：自报 MBTI(相似/荣格互补) + 兴趣 Jaccard + 地理就近 的规则打分 + 轻随机
- **安全合规底座**：联系方式/不友好内容本地审核、举报/拉黑/隐身、守护模式、GDPR 导出与删除
- **数据层**：Prisma 16 表 + 种子脚本（6 位"漂流邮局"种子写信人，密码 `inkling123`）
- **前端**：登录/引导/漂流海/我的信件/笔友信匣/我的 共 20 个页面/组件，UnoCSS 漂流邮局主题
