# Documentation

- Prefers a minimal documentation set: a root README as the high-level overview plus a single consolidated detail document, rather than many scattered docs. Confidence: 0.85
- Wants stale or redundant docs merged, simplified, and deleted (not left around), with code/config references updated to point at the consolidated doc. Confidence: 0.85
- Expects docs to distinguish what is actually implemented vs. placeholder vs. planned, so docs don't claim things the code doesn't do. Confidence: 0.6
